# Quera  – Task Manager

A daily task manager built as a team project for the Quera Front-End Bootcamp, based on the provided Figma design.

## Features

- Create tasks with a title, description and priority (high, medium, low)
- Tasks are automatically sorted by priority
- Mark tasks as completed
- Edit and delete tasks, with a confirmation dialog
- Tasks and the selected theme are saved in `localStorage`
- Light and dark mode
- Responsive layout for mobile and desktop
- Persian (RTL) interface with the Persian date

## Built With

- HTML
- Tailwind CSS
- Vanilla JavaScript
- Design tokens (CSS variables)
